4. TESTS THAT COULD NOT BE PERFORMED

  * FL Studio was NOT available. The plugin has NOT been scanned or loaded in
    FL Studio itself. FL Studio compatibility is therefore NOT verified. It
    is expected, because the plugin passes Steinberg's reference validator,
    pluginval and a JUCE-based VST3 host, but only a scan in your FL Studio can confirm it.
  * No test on a Windows 10/11 desktop installation. The tests ran on
    Windows Server 2022 and 2025 (the same Windows code base and system DLLs).
  * No test with your USB microphone or your audio driver; audio quality was
    measured with synthetic hiss and recorded speech (see docs/TEST_REPORT.md).
  * Not tested with Windows Smart App Control / third-party antivirus.

5. KNOWN LIMITATIONS
------------------------------------------------------------------------
  * The binary is not code-signed. Windows may mark the downloaded ZIP as
    coming from the internet; unblock it before extracting (INSTALLATION.txt).
    With Windows 11 Smart App Control enabled, unsigned plugins can be
    blocked from loading.
  * Latency 1024 samples at 44.1/48 kHz (23.2 / 21.3 ms), 2048 samples at
    88.2/96 kHz, reported to the host for delay compensation.
  * Built for stationary noise (constant microphone hiss, hum, fan).
    Transient noises (keyboard, clicks) are not removed.
  * Maximum mode can dull quiet "s" sounds when the hiss is loud; use Natural
    or raise Voice Preservation.
  * Mono and stereo only. Stereo channels share one gain.
