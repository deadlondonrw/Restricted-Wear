4. TESTS THAT COULD NOT BE PERFORMED
------------------------------------------------------------------------
  * FL Studio was NOT available in CI. DEADWAVE has NOT been scanned, loaded or
    played in FL Studio itself, so FL Studio compatibility is NOT verified.
    It passes Steinberg's reference validator, pluginval and a JUCE VST3 host,
    but only a scan and a test session in your FL Studio can confirm it.
  * FL Studio piano-roll slide notes: FL Studio applies slide notes to its own
    plug-ins. For VST3 instruments DEADWAVE relies on glide (overlap legato) and
    pitch bend; whether FL converts slide notes into pitch bend for a VST3 was
    not tested.
  * No test on a Windows 10/11 desktop installation (Windows Server runners).
  * No listening test with your speakers / audio interface; sound quality was
    checked with automated measurements (aliasing, pitch, levels, finite output).

5. KNOWN LIMITATIONS
------------------------------------------------------------------------
  * The binary is not code-signed: unblock the ZIP before extracting (INSTALLATION.txt).
  * The host sees about 2,800 parameters: ~720 DEADWAVE parameters plus JUCE's
    MIDI-CC proxy parameters that let VST3 hosts deliver pitch bend, mod wheel and
    aftertouch to the instrument.
  * ULTRA quality renders voices at 2x and roughly doubles the oscillator CPU cost.
